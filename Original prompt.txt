# BUILD: FREE RESOURCE INTELLIGENCE PLATFORM

You are building a production-quality web application called **Free Intel**.

This is NOT a generic "free AI tools directory."

The product is a **continuously updating Free Resource Intelligence + Cost Reduction Platform** that discovers, verifies, explains, organizes, and continuously monitors free and low-cost resources across AI, software, cloud, developer technology, business tools, and open-source ecosystems.

The primary audience is Gen-Z builders, developers, creators, students, startups, entrepreneurs, technology teams, and organizations looking to reduce technology costs.

The experience must feel futuristic, addictive, intelligent, fast, visually spectacular, and alive.

The website should make users want to explore even when they did not arrive looking for a specific resource.

# 2. ABSOLUTE COST REQUIREMENT

The application itself must be designed to operate at **$0 cost** during the initial production phase.

DO NOT introduce paid infrastructure.

DO NOT require:

* Paid LLM APIs
* Paid scraping APIs
* Paid search APIs
* Paid databases
* Paid vector databases
* Paid email services
* Paid automation platforms
* Paid monitoring services
* Paid analytics
* Paid proxy services
* Paid third-party data providers

Prefer:

* Open source
* Public APIs
* GitHub
* RSS/Atom
* Native HTTP requests
* Cloudflare free services
* GitHub Actions
* SQLite/D1
* Browser-native capabilities
* Free model inference where genuinely available
* Local computation

Every external dependency must be evaluated against the $0 requirement.

If a feature cannot realistically operate for $0, design a graceful fallback instead of silently introducing a paid dependency.
